# 3D Room Designer

Browser 3D room designer (Three.js + R3F). Drag furniture, walk through in first person.

🔗 **Live demo:** https://3d-room-zeta.vercel.app/

## Built with
`React Three Fiber` · `Three.js` · `Drei` · `Vite` · `TypeScript`

## Features
- Production-ready MERN / React architecture
- Responsive, accessible UI (mobile-first)
- Deployed on Vercel with CI
